Aktive Rules

R-01
performance-60fps
16.67ms Frame Budget — non-negotiable. Bei FPS-Drop: Feature-Freeze. Max 150 Draw Calls, 50 Physics Bodies. useFrame: keine new-Objekte, keine Heavy Computations.
R-02
design-tokens-3d
TACTICAL_TOKENS für alle Farben, Spacing und Shader-Parameter. Nie hardcoded. TACTICAL_TOKENS.colors.accent für Neon Green, .shader.bloom für Bloom-Config.
R-03
security-first-architecture
API Keys gehören niemals ins Frontend. Alle External Calls via Serverless Proxy (/api/proxy/*). Socket-Auth via JWT. HTTPS only. npm audit vor jedem Deploy.
R-04
Git Hook: API-Key-Blocker
Pre-commit Hook blockiert Commits wenn sk_*, pk_live_* oder api_key_* im Source-Code gefunden werden. Warnt bei hardcodierten Farb-Hex-Werten.
